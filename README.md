## 📋 Project Overview
This project implements 9 machine learning and deep learning models for analyzing social chatbot interactions, including:
- Traditional ML: LR, KNN, SVM, DT, LightGBM, XGBoost
- Deep Learning: CNN, GRU, B026

## 🚀 How to Run
1. Clone or download this repository
2. Open MATLAB and navigate to the project folder
3. Run the main script: `main.m` (if you have one)
4. Results will be saved in the `results/` folder

## 📊 Results Reproduction
All results reported in the paper can be reproduced by running the corresponding model files. The pre-trained models are included in this repository.
